# RMT Raw Driver — Теория и практика

> Bare-metal драйвер для модуля Remote Control Transceiver (RMT) на ESP32-S3.
> Работа напрямую с регистрами, без использования стандартного драйвера ESP-IDF.
>
> 📖 Общий гайд по регистрам и TRM: [`docs/registers_and_trm_guide.md`](../../docs/registers_and_trm_guide.md)

---

## 1. Что такое RMT

**RMT (Remote Control Transceiver)** — это аппаратный модуль в ESP32-S3, который генерирует и принимает **последовательности импульсов** с точным контролем длительности.

### Для чего используется

| Применение | Протокол / Устройство |
|-----------|----------------------|
| Управление светодиодами | WS2812B (NeoPixel), SK6812 |
| ИК-пульты | NEC, RC5, Sony SIRC |
| DHT датчики | DHT11, DHT22 (1-Wire-like) |
| Произвольные импульсы | Сигналы управления, тестирование |

### Параметры модуля в ESP32-S3

- **4 TX-канала** (Channel 0–3) — передача
- **4 RX-канала** (Channel 4–7) — приём
- **48 символов RAM** на канал (блоками по 48×32 бит)
- Программируемое **разрешение по времени** через делитель

## 2. Архитектура RMT

### Формат символа (RMT Item)

Каждый символ RMT — это **32-битное слово**, разделённое на два полуцикла:

```
  31   30        16  15   14         0
┌────┬──────────────┬────┬──────────────┐
│lvl1│   duration1  │lvl0│   duration0  │
│ 1b │    15 бит    │ 1b │    15 бит    │
└────┴──────────────┴────┴──────────────┘
```

| Поле | Биты | Описание |
|------|------|---------|
| `duration0` | [14:0] | Длительность первого полуцикла (в тиках) |
| `lvl0` | [15] | Уровень сигнала первого полуцикла (0 или 1) |
| `duration1` | [30:16] | Длительность второго полуцикла (в тиках) |
| `lvl1` | [31] | Уровень сигнала второго полуцикла (0 или 1) |

**Маркер конца**: символ, где `duration0 = 0`, означает конец передачи.

### Внутренняя структура

```
                         ┌─────────────────────────────┐
  APB Bus               │          RMT Module          │
  (CPU) ────────────────►│                              │
                         │   ┌───────────────────────┐  │
  REG_WRITE(DATA) ──────►│   │   RAM (48 символов)   │  │
                         │   │   per channel          │  │
                         │   └─────────┬─────────────┘  │
                         │             │                 │
                         │             ▼                 │
                         │   ┌───────────────────────┐  │
                         │   │    TX Engine           │  │
                         │   │  ┌─────────────────┐   │  │
  RMT_SYS_CONF_REG ────►│   │  │ Clock Divider   │   │  │
  (clock source)         │   │  │ APB/XTAL → tick │   │  │
                         │   │  └────────┬────────┘   │  │
                         │   │           ▼            │  │
                         │   │  ┌─────────────────┐   │  │
                         │   │  │ Shift Register  │   │  │
                         │   │  │ (item → pulses) │   │  │
                         │   │  └────────┬────────┘   │  │
                         │   └───────────┼────────────┘  │
                         │               ▼               │
                         │        ┌──────────────┐       │
                         │        │ GPIO Matrix  │       │
                         │        └──────┬───────┘       │
                         └───────────────┼───────────────┘
                                         ▼
                                    Физический пин
```

### Цепочка тактирования

```
  Источник           Системный        Модульный         Канальный
  частоты            делитель         делитель          делитель
┌─────────┐       ┌───────────┐     ┌──────────┐     ┌──────────┐
│ APB_CLK │──────►│ SCLK_SEL  │────►│SCLK_DIV  │────►│DIV_CNT   │────► tick
│ 80 MHz  │       │ (SYS_CONF)│     │(SYS_CONF)│     │(CHnCONF0)│
└─────────┘       └───────────┘     └──────────┘     └──────────┘

  Результирующая частота:
  resolution_hz = APB_CLK / (SCLK_DIV * DIV_CNT)
  
  Пример: 80 MHz / (1 × 80) = 1 MHz → 1 тик = 1 мкс
```

## 3. Карта ключевых регистров

### Системные (вне модуля RMT)

| Регистр | Адрес | Назначение |
|---------|-------|-----------|
| `SYSTEM_PERIP_CLK_EN0_REG` | системный | Включение тактового сигнала для периферии |
| `SYSTEM_PERIP_RST_EN0_REG` | системный | Снятие сброса периферии |

### Модуль RMT

| Регистр | Смещение | Назначение |
|---------|----------|-----------|
| `RMT_CH0DATA_REG` | `0x00` | Данные канала 0 (запись символов) |
| `RMT_CH0CONF0_REG` | `0x20` | Конфигурация канала 0: старт, сброс, делитель, память, защёлка |
| `RMT_INT_RAW_REG` | `0x70` | Сырые флаги прерываний (TX_END, ERR, и т.д.) |
| `RMT_INT_CLR_REG` | `0x7C`* | Очистка флагов прерываний |
| `RMT_SYS_CONF_REG` | `0xC0` | Системная конфигурация: источник частоты, clock gate, FIFO mask |

### Побитовая карта `RMT_CH0CONF0_REG` (0x20)

```
Бит    Имя                     Тип   Описание
──────────────────────────────────────────────────────────────
[0]    TX_START_CH0            WT    Старт передачи
[1]    MEM_RD_RST_CH0         WT    Сброс указателя чтения
[2]    APB_MEM_RST_CH0        WT    Сброс указателя записи (APB FIFO)
[3]    TX_CONTI_MODE_CH0      R/W   Непрерывный режим
[4]    MEM_TX_WRAP_EN_CH0     R/W   Режим закольцовки памяти
[5]    IDLE_OUT_LV_CH0        R/W   Уровень сигнала в IDLE (0 или 1)
[6]    IDLE_OUT_EN_CH0        R/W   Разрешить управление выходом в IDLE
[7]    TX_STOP_CH0            R/W/SC Остановить передачу
[15:8] DIV_CNT_CH0            R/W   Делитель частоты (8 бит, 0-255)
[19:16] MEM_SIZE_CH0          R/W   Количество блоков RAM (1 блок = 48 символов)
[20]   CARRIER_EFF_EN_CH0     R/W   Несущая только при передаче данных
[21]   CARRIER_EN_CH0         R/W   Включить модуляцию несущей
[22]   CARRIER_OUT_LV_CH0     R/W   Полярность несущей
[23]   AFIFO_RST_CH0          WT    Сброс AFIFO (зарезервировано)
[24]   CONF_UPDATE_CH0        WT    🔑 ЗАЩЁЛКА — применить все настройки!
```

### Побитовая карта `RMT_SYS_CONF_REG` (0xC0)

```
Бит     Имя                Тип   Описание
──────────────────────────────────────────────────────────────
[0]     APB_FIFO_MASK      R/W   1 = прямой доступ к RAM, 0 = через FIFO
[1]     MEM_CLK_FORCE_ON   R/W   Принудительное тактирование RAM
[2]     MEM_FORCE_PD       R/W   Принудительное отключение памяти
[3]     MEM_FORCE_PU       R/W   Принудительное включение памяти
[11:4]  SCLK_DIV_NUM       R/W   Целая часть делителя источника
[17:12] SCLK_DIV_A         R/W   Числитель дробной части
[23:18] SCLK_DIV_B         R/W   Знаменатель дробной части
[25:24] SCLK_SEL           R/W   Выбор источника: 1=APB(80M), 2=8M, 3=XTAL
[26]    SCLK_ACTIVE        R/W   Включить тактирование модуля
[31]    CLK_EN             R/W   Clock gate регистров модуля
```

## 4. Флоу настройки RMT через регистры

Ниже — последовательность действий, привязанная к коду в [`rmt_raw.c`](./rmt_raw.c).

### ШАГ 0: Системное тактирование

📍 **Код**: [`rmt_raw.c:24-25`](./rmt_raw.c#L24-L25)

Включаем тактовый сигнал для модуля RMT на уровне системы и снимаем сброс.

```c
REG_WRITE(SYSTEM_PERIP_CLK_EN0_REG, ... | SYSTEM_RMT_CLK_EN);  // Подать тактирование
REG_WRITE(SYSTEM_PERIP_RST_EN0_REG, ... & ~SYSTEM_RMT_RST);    // Снять сброс
```

> ⚠️ **Без этого шага все дальнейшие записи в регистры RMT бессмысленны** — модуль просто не «слышит» шину.

### ШАГ 1: Маршрутизация GPIO

📍 **Код**: [`rmt_raw.c:30-32`](./rmt_raw.c#L30-L32)

Подключаем выход TX канала 0 к физическому пину через GPIO Matrix.

```c
esp_rom_gpio_pad_select_gpio(gpio);                              // Выбираем пин как GPIO
gpio_set_direction(gpio, GPIO_MODE_OUTPUT);                      // Направление — выход
esp_rom_gpio_connect_out_signal(gpio, RMT_SIG_OUT0_IDX, ...);   // RMT CH0 → пин
```

### ШАГ 2: Тактирование модуля (`RMT_SYS_CONF_REG`)

📍 **Код**: [`rmt_raw.c:40-61`](./rmt_raw.c#L40-L61)

Настраиваем внутреннее тактирование RMT:

| Действие | Бит | Значение |
|----------|-----|---------|
| Clock gate регистров | `CLK_EN` [31] | → 1 |
| Выбор источника | `SCLK_SEL` [25:24] | → 1 (APB 80MHz) |
| Прямой доступ к RAM | `APB_FIFO_MASK` [0] | → 1 |

### ШАГ 3: Конфигурация канала (`RMT_CH0CONF0_REG`)

📍 **Код**: [`rmt_raw.c:71-115`](./rmt_raw.c#L71-L115)

| Действие | Бит | Значение |
|----------|-----|---------|
| Делитель частоты | `DIV_CNT` [15:8] | 80 (→ 1 MHz) |
| Блоков RAM | `MEM_SIZE` [19:16] | 1 (48 символов) |
| Выход в IDLE | `IDLE_OUT_EN` [6] | → 1 (включить) |
| Уровень в IDLE | `IDLE_OUT_LV` [5] | → 0 (LOW) |
| Continuous mode | `TX_CONTI_MODE` [3] | → 0 (выкл) |
| Wrap mode | `MEM_TX_WRAP_EN` [4] | → 0 (выкл) |
| Сброс RAM | `APB_MEM_RST` [2] | 1 → 0 (импульс) |

### ШАГ 4: Защёлка! (`CONF_UPDATE`)

📍 **Код**: [`rmt_raw.c:123-128`](./rmt_raw.c#L123-L128)

```c
ch0conf0 |= (1 << 24);                   // RMT_CONF_UPDATE_CH0
REG_WRITE(RMT_CH0CONF0_REG, ch0conf0);   // Применяем ВСЕ настройки разом
```

> 🔑 Без записи `CONF_UPDATE` аппаратура будет работать со **старыми** настройками.

## 8. Демонстрация (main.c)

В [`main/main.c`](../../main/main.c) реализовано несколько демо-примеров использования bare-metal драйвера:
- Ручная отправка массивов `rmt_item_t` (`send_items`)
- Генерация последовательности импульсов с чередованием полярности (`send_pulses`)
- Генерация ШИМ-сигнала (меандра) с заданными частотой и скважностью (`square`)

Это позволяет на осциллографе или логическом анализаторе убедиться в правильности генерации сигналов, опираясь исключительно на конфигурацию регистров.
