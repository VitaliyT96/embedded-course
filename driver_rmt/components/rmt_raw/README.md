# RMT Raw Driver — Теорія та практика

> Bare-metal драйвер для модуля Remote Control Transceiver (RMT) на ESP32-S3.
> Робота безпосередньо з регістрами, без використання стандартного драйвера ESP-IDF.
>
> 📖 Загальний посібник з регістрів та TRM: [`docs/registers_and_trm_guide.md`](../../docs/registers_and_trm_guide.md)

---

## 1. Що таке RMT

**RMT (Remote Control Transceiver)** — це апаратний модуль у ESP32-S3, який генерує та приймає **послідовності імпульсів** із точним контролем тривалості.

### Для чого використовується

| Застосування | Протокол / Пристрій |
|-----------|----------------------|
| Керування світлодіодами | WS2812B (NeoPixel), SK6812 |
| ІЧ-пульти | NEC, RC5, Sony SIRC |
| DHT датчики | DHT11, DHT22 (1-Wire-like) |
| Довільні імпульси | Сигнали керування, тестування |

### Параметри модуля в ESP32-S3

- **4 TX-канали** (Channel 0–3) — передача
- **4 RX-канали** (Channel 4–7) — прийом
- **48 символів RAM** на канал (блоками по 48×32 біт)
- Програмована **роздільна здатність за часом** через дільник

## 2. Архітектура RMT

### Формат символу (RMT Item)

Кожен символ RMT — це **32-бітне слово**, розділене на два напівцикли:

```
  31   30        16  15   14         0
┌────┬──────────────┬────┬──────────────┐
│lvl1│   duration1  │lvl0│   duration0  │
│ 1b │    15 біт    │ 1b │    15 біт    │
└────┴──────────────┴────┴──────────────┘
```

| Поле | Біти | Опис |
|------|------|---------|
| `duration0` | [14:0] | Тривалість першого напівциклу (у тіках) |
| `lvl0` | [15] | Рівень сигналу першого напівциклу (0 або 1) |
| `duration1` | [30:16] | Тривалість другого напівциклу (у тіках) |
| `lvl1` | [31] | Рівень сигналу другого напівциклу (0 або 1) |

**Маркер кінця**: символ, де `duration0 = 0`, означає кінець передачі.

### Внутрішня структура

```
                         ┌─────────────────────────────┐
  APB Bus               │          RMT Module          │
  (CPU) ────────────────►│                              │
                         │   ┌───────────────────────┐  │
  REG_WRITE(DATA) ──────►│   │   RAM (48 символів)   │  │
                         │   │   per channel          │  │
                         │   └─────────┬─────────────┘  │
                         │             │                 │
                         │             ▼                 │
                         │   ┌───────────────────────┐  │
                         │   │    TX Engine           │  │
                         │   │  ┌─────────────────┐   │  │
  RMT_SYS_CONF_REG ────►│   │  │ Clock Divider   │   │  │
  (clock source)         │   │  │ APB/XTAL → tick │   │  │
                         │   │  └────────┬────────┘   │  │
                         │   │           ▼            │  │
                         │   │  ┌─────────────────┐   │  │
                         │   │  │ Shift Register  │   │  │
                         │   │  │ (item → pulses) │   │  │
                         │   │  └────────┬────────┘   │  │
                         │   └───────────┼────────────┘  │
                         │               ▼               │
                         │        ┌──────────────┐       │
                         │        │ GPIO Matrix  │       │
                         │        └──────┬───────┘       │
                         └───────────────┼───────────────┘
                                         ▼
                                    Фізичний пін
```

### Ланцюжок тактування

```
  Джерело            Системний        Модульний         Канальний
  частоти            дільник          дільник           дільник
┌─────────┐       ┌───────────┐     ┌──────────┐     ┌──────────┐
│ APB_CLK │──────►│ SCLK_SEL  │────►│SCLK_DIV  │────►│DIV_CNT   │────► tick
│ 80 MHz  │       │ (SYS_CONF)│     │(SYS_CONF)│     │(CHnCONF0)│
└─────────┘       └───────────┘     └──────────┘     └──────────┘

  Результуюча частота:
  resolution_hz = APB_CLK / (SCLK_DIV * DIV_CNT)
  
  Приклад: 80 MHz / (1 × 80) = 1 MHz → 1 тік = 1 мкс
```

## 3. Карта ключових регістрів

### Системні (поза модулем RMT)

| Регістр | Адреса | Призначення |
|---------|-------|-----------|
| `SYSTEM_PERIP_CLK_EN0_REG` | системний | Увімкнення тактового сигналу для периферії |
| `SYSTEM_PERIP_RST_EN0_REG` | системний | Зняття скидання периферії |

### Модуль RMT

| Регістр | Зсув | Призначення |
|---------|----------|-----------|
| `RMT_CH0DATA_REG` | `0x00` | Дані каналу 0 (запис символів) |
| `RMT_CH0CONF0_REG` | `0x20` | Конфігурація каналу 0: старт, скидання, дільник, пам'ять, защіпка |
| `RMT_INT_RAW_REG` | `0x70` | Сирі прапорці переривань (TX_END, ERR, тощо) |
| `RMT_INT_CLR_REG` | `0x7C`* | Очищення прапорців переривань |
| `RMT_SYS_CONF_REG` | `0xC0` | Системна конфігурація: джерело частоти, clock gate, FIFO mask |

### Побітова карта `RMT_CH0CONF0_REG` (0x20)

```
Біт    Ім'я                    Тип   Опис
──────────────────────────────────────────────────────────────
[0]    TX_START_CH0            WT    Старт передачі
[1]    MEM_RD_RST_CH0         WT    Скидання вказівника читання
[2]    APB_MEM_RST_CH0        WT    Скидання вказівника запису (APB FIFO)
[3]    TX_CONTI_MODE_CH0      R/W   Безперервний режим
[4]    MEM_TX_WRAP_EN_CH0     R/W   Режим зациклення пам'яті
[5]    IDLE_OUT_LV_CH0        R/W   Рівень сигналу в IDLE (0 або 1)
[6]    IDLE_OUT_EN_CH0        R/W   Дозволити керування виходом в IDLE
[7]    TX_STOP_CH0            R/W/SC Зупинити передачу
[15:8] DIV_CNT_CH0            R/W   Дільник частоти (8 біт, 0-255)
[19:16] MEM_SIZE_CH0          R/W   Кількість блоків RAM (1 блок = 48 символів)
[20]   CARRIER_EFF_EN_CH0     R/W   Несуча тільки під час передачі даних
[21]   CARRIER_EN_CH0         R/W   Увімкнути модуляцію несучої
[22]   CARRIER_OUT_LV_CH0     R/W   Полярність несучої
[23]   AFIFO_RST_CH0          WT    Скидання AFIFO (зарезервовано)
[24]   CONF_UPDATE_CH0        WT    🔑 ЗАЩІПКА — застосувати всі налаштування!
```

### Побітова карта `RMT_SYS_CONF_REG` (0xC0)

```
Біт     Ім'я               Тип   Опис
──────────────────────────────────────────────────────────────
[0]     APB_FIFO_MASK      R/W   1 = прямий доступ до RAM, 0 = через FIFO
[1]     MEM_CLK_FORCE_ON   R/W   Примусове тактування RAM
[2]     MEM_FORCE_PD       R/W   Примусове відключення пам'яті
[3]     MEM_FORCE_PU       R/W   Примусове увімкнення пам'яті
[11:4]  SCLK_DIV_NUM       R/W   Ціла частина дільника джерела
[17:12] SCLK_DIV_A         R/W   Чисельник дробової частини
[23:18] SCLK_DIV_B         R/W   Знаменник дробової частини
[25:24] SCLK_SEL           R/W   Вибір джерела: 1=APB(80M), 2=8M, 3=XTAL
[26]    SCLK_ACTIVE        R/W   Увімкнути тактування модуля
[31]    CLK_EN             R/W   Clock gate регістрів модуля
```

## 4. Флоу налаштування RMT через регістри

Нижче — послідовність дій, прив'язана до коду в [`rmt_raw.c`](./rmt_raw.c).

### КРОК 0: Системне тактування

📍 **Код**: [`rmt_raw.c:24-25`](./rmt_raw.c#L24-L25)

Вмикаємо тактовий сигнал для модуля RMT на рівні системи та знімаємо скидання.

```c
REG_WRITE(SYSTEM_PERIP_CLK_EN0_REG, ... | SYSTEM_RMT_CLK_EN);  // Подати тактування
REG_WRITE(SYSTEM_PERIP_RST_EN0_REG, ... & ~SYSTEM_RMT_RST);    // Зняти скидання
```

> ⚠️ **Без цього кроку всі подальші записи в регістри RMT безглузді** — модуль просто не «чує» шину.

### КРОК 1: Маршрутизація GPIO

📍 **Код**: [`rmt_raw.c:30-32`](./rmt_raw.c#L30-L32)

Підключаємо вихід TX каналу 0 до фізичного піна через GPIO Matrix.

```c
esp_rom_gpio_pad_select_gpio(gpio);                              // Вибираємо пін як GPIO
gpio_set_direction(gpio, GPIO_MODE_OUTPUT);                      // Напрямок — вихід
esp_rom_gpio_connect_out_signal(gpio, RMT_SIG_OUT0_IDX, ...);   // RMT CH0 → пін
```

### КРОК 2: Тактування модуля (`RMT_SYS_CONF_REG`)

📍 **Код**: [`rmt_raw.c:40-61`](./rmt_raw.c#L40-L61)

Налаштовуємо внутрішнє тактування RMT:

| Дія | Біт | Значення |
|----------|-----|---------|
| Clock gate регістрів | `CLK_EN` [31] | → 1 |
| Вибір джерела | `SCLK_SEL` [25:24] | → 1 (APB 80MHz) |
| Прямий доступ до RAM | `APB_FIFO_MASK` [0] | → 1 |

### КРОК 3: Конфігурація каналу (`RMT_CH0CONF0_REG`)

📍 **Код**: [`rmt_raw.c:71-115`](./rmt_raw.c#L71-L115)

| Дія | Біт | Значення |
|----------|-----|---------|
| Дільник частоти | `DIV_CNT` [15:8] | 80 (→ 1 MHz) |
| Блоків RAM | `MEM_SIZE` [19:16] | 1 (48 символів) |
| Вихід в IDLE | `IDLE_OUT_EN` [6] | → 1 (увімкнути) |
| Рівень в IDLE | `IDLE_OUT_LV` [5] | → 0 (LOW) |
| Continuous mode | `TX_CONTI_MODE` [3] | → 0 (вимк) |
| Wrap mode | `MEM_TX_WRAP_EN` [4] | → 0 (вимк) |
| Скидання RAM | `APB_MEM_RST` [2] | 1 → 0 (імпульс) |

### КРОК 4: Защіпка! (`CONF_UPDATE`)

📍 **Код**: [`rmt_raw.c:123-128`](./rmt_raw.c#L123-L128)

```c
ch0conf0 |= (1 << 24);                   // RMT_CONF_UPDATE_CH0
REG_WRITE(RMT_CH0CONF0_REG, ch0conf0);   // Застосовуємо ВСІ налаштування разом
```

> 🔑 Без запису `CONF_UPDATE` апаратура працюватиме зі **старими** налаштуваннями.

📍 **Код**: [`rmt_raw.c:132-198`](./rmt_raw.c#L132-L198)

```
┌──────────────────────────────────────────────────────────┐
│                    ПЕРЕДАЧА ДАНИХ                         │

│  ④ Скидання read pointer                                 │
│     MEM_RD_RST = 1 → CONF_UPDATE → MEM_RD_RST = 0       │
│                                                          │
│  ⑤ Старт: TX_START = 1 + CONF_UPDATE                    │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

## 6. Очікування завершення

📍 **Код**: [`rmt_raw.c:200-221`](./rmt_raw.c#L200-L221)

```
  RMT_INT_RAW_REG
  ┌─────────────────────────────────────────────────┐
  │ біт 0: CH0_TX_END_INT_RAW                       │
  │        Апаратура ставить 1, коли передача       │
  │        каналу 0 завершена.                      │
  └─────────────────────────────────────────────────┘
         │
         ▼
  Polling: while ((REG_READ(RMT_INT_RAW_REG) & 1) == 0) { }
         │
         ▼
  Очищення: REG_WRITE(RMT_INT_CLR_REG, 1)
            (Записати 1 в біт 0 CLR-регістра)
```

## 8. Демонстрація (main.c)

У [`main/main.c`](../../main/main.c) реалізовано кілька демо-прикладів використання bare-metal драйвера:
- Ручна відправка масивів `rmt_item_t` (`send_items`)
- Генерація послідовності імпульсів із чергуванням полярності (`send_pulses`)
- Генерація ШІМ-сигналу (меандру) із заданими частотою та шпаруватістю (`square`)

Це дозволяє на осцилографі або логічному аналізаторі переконатися в правильності генерації сигналів, спираючись виключно на конфігурацію регістрів.
